# Active Directory Security and Attacks Lab

## Goal

The goal of this project is to build a realistic Active Directory Attack and Defense lab to understand how attackers compromise Windows domain environments and how defenders detect and mitigate those attacks.

This project focuses on understanding Active Directory authentication, authorization, common attack techniques, privilege escalation, reconnaissance, credential theft, and defensive monitoring using Windows event logs and security tools.

## Learning Objectives

- Understand Active Directory security architecture.
- Learn Kerberos, NTLM, LDAP and authentication flow.
- Perform common Active Directory attacks in a safe lab.
- Detect malicious activities using Windows Event Logs and Sysmon.
- Practice Active Directory hardening and mitigation techniques.

## Disclaimer

This project is created for educational purposes inside a controlled lab environment.
No attacks are performed against production systems.
